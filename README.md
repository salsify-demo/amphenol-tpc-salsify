# Amphenol TPC Wire & Cable × Salsify

Responsive single-page site (plain HTML, CSS and JS, no build step).

Live: https://salsify-demo.github.io/amphenol-tpc-salsify/

```
index.html        page content
css/styles.css    styles (mobile-first breakpoints at 960 / 860 / 760 / 520px)
js/main.js        mobile menu, scroll reveal, active nav link, count-up numbers
assets/           Salsify logo, favicon
```
